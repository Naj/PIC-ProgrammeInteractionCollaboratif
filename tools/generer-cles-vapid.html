Générer les clés de notification

Cette page fabrique la paire de clés VAPID nécessaire aux rappels du matin. Tout se passe dans votre navigateur : rien n'est envoyé nulle part, et aucune connexion réseau n'est utilisée.

Elle fonctionne par simple double-clic sur le fichier, sans serveur ni installation.

À renseigner deux fois : en variable d'environnement du projet Pages, et en secret du worker de rappels.

Secret du worker uniquement. Ne la publiez jamais dans le dépôt GitHub.

Votre adresse de contact, exigée par les services de notification.

Conservez ces deux clés maintenant. Cette page ne les enregistre pas : fermez-la et elles sont perdues. Une nouvelle paire invaliderait tous les abonnements déjà enregistrés, qu'il faudrait réactiver appareil par appareil.
  1. Tableau de bord Cloudflare → votre worker pic-rappels → Settings → Variables and Secrets.
  2. Ajoutez les trois valeurs ci-dessus, chacune en type Secret.
  3. Ajoutez aussi CRON_TEST_KEY, une chaîne au choix, pour pouvoir déclencher un rappel à la demande.
  4. Dans le projet Pages → Settings → variables d'environnement : ajoutez VAPID_PUBLIC avec la même valeur.
